# SlidFix — калькулятор креплений для стены

Интерактивный калькулятор раскладки креплений SlidFix: геометрия стены и проёмов,
SVG-схема, количество креплений, упаковок и шурупов. Проект продолжает исходный
HTML/CSS/JS-прототип из архива и работает как **zero-build static website**.
React, Next.js, Vite, npm и зависимости для запуска не требуются.

> IMPORTANT:
> The current fastener spacing and placement algorithm is a UX/demo model.
> It must not be treated as final installation engineering guidance until SlidFix engineering rules are validated.

Это публичная демонстрация интерфейса, а не утверждённый монтажный расчёт.
Исходные демонстрационные шаги и отступы не заменены выдуманными инженерными нормами.

## Публичная русскоязычная версия

Весь интерфейс, сообщения проверки ввода, подписи размеров и результатов,
доступные названия элементов и тексты экспортируемой SVG-схемы переведены на русский.
Площади и размерные подписи используют десятичную запятую. В HTML задан `lang="ru"`.

Верхний рендер изделия и технический разрез полностью удалены из разметки.
Вместо рендера используется абстрактная координатная сетка, вместо разреза —
текстовая панель «Условные обозначения». Единственное изображение, загружаемое
интерфейсом, — логотип SlidFix. Красно-белые маркеры показывают только точки установки.

SVG содержит стену, проёмы, маркеры и размеры, без изображений и устройства
крепления. JSON содержит параметры расчёта, координаты и количества, без ссылок
на изображения или описания конструкции изделия. Ключи JSON и служебные значения
режимов оставлены прежними для совместимости; предупреждение переведено на русский.

Исходные изображения в `assets/` сохранены по заданию для дальнейшей разработки.
Они не используются в HTML, CSS или JavaScript, за исключением логотипа.
Это скрытие из интерфейса, а не ограничение доступа: файлы остаются доступны
в публичном репозитории и по прямым адресам статического хостинга.
Исторические материалы в `docs/`, включая `COPY_EN.txt`, не подключены к интерфейсу.

В интерфейсе и экспортах используется предупреждение:

> Предварительный расчёт. Текущие параметры шага и расстановки используются для демонстрации работы калькулятора и будут уточнены после утверждения инженерного регламента SlidFix.

## Возможности

- Blank wall, Window center, Door left, Door center, Two windows.
- Standard и Staggered placement; Standard и Dense spacing.
- Изменение ширины/высоты стены, ширины доски, шага обрешётки и размеров проёмов.
- Автоматическое обновление SVG-схемы с сохранением пропорций стены.
- Исключение креплений из проёмов и окружающей демонстрационной зоны отступа.
- Площадь стены до и после вычитания проёмов, условное число рядов доски,
  SlidFix units, packs и screws.
- Скачивание самостоятельного SVG и проекта JSON.
- Адаптивная компоновка, клавиатурный фокус и состояния выбранных кнопок.

Корзина не подключена: кнопка явно отключена. PDF, отправка дилеру, импорт JSON
и оформление заказа в этой версии не реализованы.

## Локальный запуск

Из корня репозитория:

```sh
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Остановить сервер: `Ctrl+C`.
Python используется только как локальный HTTP-сервер; на хостинге он не нужен.

## Публикация в GitHub Pages

В репозитории `turboparenone/slidfix-calculator` откройте **Settings → Pages**:

1. **Build and deployment → Source:** `Deploy from a branch`.
2. **Branch:** `main`.
3. **Folder:** `/ (root)`.
4. Нажмите **Save** и дождитесь успешного развёртывания Pages.

Ожидаемый URL: [https://turboparenone.github.io/slidfix-calculator/](https://turboparenone.github.io/slidfix-calculator/).
Он начнёт обслуживать сайт после включения Pages и завершения развёртывания.
Файл `.nojekyll` отключает обработку Jekyll. Все пути к CSS, JS и изображениям
относительные, поэтому сайт работает в подпапке `/slidfix-calculator/`.
Никакие build-команды или GitHub Actions workflow добавлять не требуется.

## Как считается результат

Константы находятся в `ENGINEERING` в `app.js`:

| Параметр | Значение | Статус |
| --- | --- | --- |
| SlidFix в упаковке | 10 | Задано в брифе |
| Шурупов на SlidFix | 2 | Задано в брифе |
| Вертикальный шаг Standard | 500 мм | UX/demo placeholder |
| Вертикальный шаг Dense | 350 мм | UX/demo placeholder |
| Отступ от края стены | 180 мм | UX/demo placeholder |
| Отступ от проёма | 110 мм | UX/demo placeholder |

Горизонтальный шаг берётся из Batten spacing. В Staggered каждый второй ряд
смещается на половину этого шага. Считаются только допустимые точки вне проёмов
и зоны отступа. Координаты проекта заданы в метрах от левого нижнего угла стены.
Двери имеют `y = 0` и касаются нижней границы стены.

```text
SlidFix units = число допустимых точек
Packs = ceil(SlidFix units / 10)
Screws = SlidFix units × 2
Gross area = wall width × wall height
Net area = gross area − сумма площадей проёмов
Board courses = ceil(wall height × 1000 / board width)
```

Board courses — сохранённый условный показатель прототипа, не ведомость закупки
досок. Изменение ширины доски влияет на визуализацию и этот показатель, но не
на сетку креплений: её зависимость от доски требует инженерного подтверждения.

Размеры проёмов ограничиваются выбранным пресетом и размерами стены; поля
показывают фактически используемые значения. У Two windows размеры относятся
к каждому окну. У Blank wall поля проёмов скрыты и отключены. Невалидный ввод
не ломает расчёт: до завершения редактирования сохраняется последнее корректное
значение, затем ввод приводится к допустимому диапазону.

## Экспорт

- `slidfix-wall-layout.svg`: текущая схема, фон, размерные линии, маркеры,
  видимая пометка «ПРЕДВАРИТЕЛЬНАЯ СХЕМА» и русское предупреждение в SVG description.
- `slidfix-project.json`: бренд, дата, параметры формы, demo-константы,
  геометрия проёмов, точки, количество креплений/упаковок/шурупов и предупреждение.

Файлы формируются в браузере. Калькулятор не отправляет параметры стены на сервер.

## Проверка перед публикацией

Проверено через Python HTTP-сервер и headless Chromium. Инструменты проверки
были временными и не входят в сайт; установка Node/npm для его работы не нужна.

| Проверка | Результат |
| --- | --- |
| Blank wall, 6 × 2,8 м, шаг 600 мм, Standard | 50 SlidFix, без проёмов |
| Window center | Одно центрированное по ширине окно, креплений в зоне проёма нет |
| Door left | Дверь слева, нижняя координата 0 |
| Door center | Дверь по центру, нижняя координата 0 |
| Two windows | Два раздельных окна, креплений в проёмах нет |
| Ширина пустой стены 6 → 8 м | Схема и площадь обновляются; 50 → 65 SlidFix |
| Standard → Staggered | Каждый второй ряд смещён; 50 → 48 SlidFix на пустой стене |
| Standard → Dense в Staggered | 48 → 67 SlidFix |
| Упаковки и шурупы | Для 67 SlidFix: 7 упаковок, 134 шурупа |
| SVG и JSON | Реальные скачивания; содержимое и числа проверены |
| Дополнительные размеры | Высота стены, ширина доски, шаг 200 мм и размеры всех проёмов работают |
| Клавиатурный ввод | Дробные значения 8.2, 1.25 и 0.9 вводятся посимвольно |
| Некорректные числа | Пустые, отрицательные и превышающие предел значения обработаны |
| Responsive | 1440, 1024 и 390 px, без горизонтального переполнения |
| Изображения | Все 11 файлов загружаются и декодируются |
| Браузер | Нет JS/console errors и неудачных HTTP-запросов |
| Подпапка GitHub Pages | Загрузка относительных CSS, JS и изображений проверена с префиксом пути |

Полное инженерное обоснование ещё необходимо. Перечень открытых вопросов
и логика демонстрации находятся в `docs/CALCULATION_LOGIC_RU.md`.


### Проверка русскоязычной версии

- Пройдены все 20 сочетаний пяти типов стены, двух схем и двух плотностей.
- Результаты исходного расчёта сохранены: пустая стена 6 → 8 м — 50 → 65 креплений;
  шахматная схема со стандартной → усиленной плотностью — 48 → 67 креплений.
- Проверены изменения размеров стены, доски, обрешётки и проёмов, а также сообщение
  о некорректном вводе на русском языке.
- Видимые тексты, aria-label, title/description и SVG проверены на английские слова;
  остались только название SlidFix и обозначения форматов SVG/JSON.
- SVG и JSON скачаны и проверены: количества верны, конструкция изделия и пути
  к изображениям отсутствуют.
- На 1440, 1024 и 390 px нет горизонтального переполнения; легенда и элементы
  управления доступны. Все три размера проверены по снимкам экрана.
- Сетевой журнал подтверждает: из `assets/` загружается только логотип.
  Ошибок JavaScript, консоли и HTTP-запросов не обнаружено.
